How it works

Three steps. One of them is a click.

  1. 01

    Install the agent on the instrument PC

    One file, run with Node.js on the results folder. It reads only bytes: any instrument, any vendor, any format.

    > node iqc.mjs watch "D:\Results"

  2. 02

    Every file is sealed as it is written

    Each new or changed file gets a SHA-256 fingerprint and a signature, chained into a ledger inside that folder.

    sealed plate-07.csv 477f09c4…

  3. 03

    Drop the folder to audit it in one click

    Anyone with the folder drops it on the app: every file matches its seal, or you see exactly which do not.

    Pass All 5 files match.

A pass shows

Each file is byte-for-byte the one the agent sealed, and the ledger has not been edited, reordered or cut since it was signed.

It does not show

That a file was right when it was written, or a change in the few seconds before the agent reads a new file. Whoever holds the ledger’s key could rewrite it from the start; a head pinned elsewhere exposes that.

A change on the instrument PC while the agent runs is sealed as a new version, with its time; the audit lists every version.

Why it matters

Most bad data is not malicious.

Quiet accidents

A script rewrites a column, a sync conflict keeps the wrong copy, a backup lands over newer results. Nobody meant to change anything.

Results that steer

Results now feed models that choose the next experiment, so one wrong value travels into every run after it.

Nothing readable leaves

The ledger holds fingerprints, not data. Audits run in your browser, and the app is blocked from connecting anywhere.

To pin the ledger somewhere else, you share only its head: a record number and a 64-character link that reveals none of your data.

Install

Get the agent.

One file, no dependencies. Needs Node.js 20 or later on Windows, macOS or Linux.

1 · Download

Download iqc.mjs
SHA-256 of iqc.mjs

594c2324af656aedb1d36791392c3ce48e9482da34e07560bc1bbd029e2f6410

Check your download:

  • Windowscertutil -hashfile iqc.mjs SHA256
  • macOS, Linuxshasum -a 256 iqc.mjs

2 · Run one command

On the instrument PC
> node iqc.mjs watch "D:\Results"

It seals the folder now, then each new or changed file until you press Ctrl+C.

What it touches

Reads
Every file in the folder, read-only. It skips symlinks and system files.
Writes
Only ImmutableQC/ledger.jsonl, README.txt and agent.lock in that folder, and its private key in ~/.immutableqc/keys/, readable only by you.
Network
None.
Runs as
You: no installer, no service. It stops on Ctrl+C, and records the stop.
In a scheduler or a pipeline
# seal once and exit
node iqc.mjs seal "D:\Results"
# print the head, to pin it somewhere else
node iqc.mjs head "D:\Results"
# exit 0 pass, 1 fail, 2 usage or read error
node iqc.mjs audit "D:\Results" --expect-head <n>:<h> --json audit.json

See a pass and a fail in under a minute.
