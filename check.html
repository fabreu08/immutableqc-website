System suitability: 5 replicate injections of the reference standard, peak-area RSD 0.20% (computed at build). Sample peak areas are 99.0%, 100.5%, 99.5% of the standard mean. Synthetic data.

How to read it: each record’s link is checked from the previous link it stores, so a changed value fails that record’s fingerprint and signature and breaks only the link into the next record. The anchor check replays the whole history from 64 zeros, so after any change the head no longer matches.

Note Demo signatures. In the alpha, one server key signs imported rows; per-analyst signatures are on the roadmap.

An agent would recompute the fingerprint from the fields, check the signature with the public key, recompute the link from the previous link the record stores, and replay the history to compare the anchor. Only if all four pass would it treat the record as unchanged since sealing; in use, it would take the public key and the anchor from outside the lab’s system.

3Method

  • PayloadinstrumentId|sensorType|value|unit|capturedAt, UTF-8, no spaces around the bars: the alpha app’s canonical payload for an HPLC peak area. The alpha records peak area with the unit “counts”.
  • Fingerprintrn = SHA-256 of the payload (FIPS 180-4), as lowercase hex. Check: the recomputed rn against the stored one.
  • Linkhn = SHA-256 of the text hn−1 + rn + n (lowercase hex, then the decimal position), starting from 64 zeros. Check: SHA-256 of the previous link the record stores, its recomputed fingerprint and n, against the link it stores, which the next record carries. A changed value breaks only the link into the next record.
  • SignatureECDSA P-256 with SHA-256 over the 32 bytes of rn (FIPS 186-5), IEEE P1363 encoding, checked against the recomputed fingerprint. Records 1 to 8 were signed at build time with a demo key whose private half was then discarded. Demo key id 7A15F56288146023D45A47796F6A5553 (first 16 bytes of SHA-256 of its SPKI). Public key, uncompressed point:0458f36cfc0c1e0df9d1b97e3cd6e3e3ca7bc3acd4fa6b835584f63aa4551ef83855cbc7609030d0ddbe6a92bdb73176884a951eb6ba33eece29bdcb30d6b7c66f
  • AnchorThe whole history replayed from 64 zeros over the recomputed fingerprints; the replayed link of record 8 against the anchored fingerprint stored on this page (simulated, no network call). A correction moves the head on; it stays “not yet anchored” until a new anchor.
  • PassA record passes when its fingerprint and link check and its signature does not fail. Without the browser’s own checking tools (an http:// page), fingerprints and links are recomputed with a SHA-256 built into the page and signatures are not checked.
  • LimitsOn this page the public key and the anchor ship with the records, so they show the method, not independent evidence: whoever can rewrite the page can replace the key, the signatures and the anchor together. In use, both must come from outside the lab’s system: a key published elsewhere, a fingerprint on a public network.

BasisThe same payload and link rule as the alpha app’s HPLC import; the same link rule as the record figure on joseqc.com.
