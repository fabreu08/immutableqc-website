Drop a data folder to audit it

The app finds ImmutableQC/ledger.jsonl inside it and starts at once: every file re-read, every seal and link checked.

Try it with sample data

Any file type. Large files are read in 8 MiB slices, so they never have to fit in memory.

Nothing is uploaded: your browser reads the files, and this page is not allowed to open a connection.

Pinned head and expected key id Optional

From iqc head or an earlier report: a record number, a colon and a 64-character link. A ledger rewritten since will not match it.

The key id from an earlier report: a ledger signed with another key will not match it.

No ledger in the folder? The app asks for the ledger file next.

Where is the ledger?

The agent writes it as ImmutableQC/ledger.jsonl inside the data folder, unless it was told to keep it somewhere else.

Drop a data folder to seal it

Your browser fingerprints every file and signs the list with a key it keeps. You get ledger.jsonl, to put in an ImmutableQC folder inside the data folder.

If the folder has a ledger whose key this browser holds, a scan and the changes since are added to it.

Nothing is uploaded. The key stays in this browser, which cannot export it.

Station name Optional

Sealed into every record: where it was made. 1 to 64 characters; “Browser” when left empty.
