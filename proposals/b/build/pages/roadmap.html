Roadmap

1Today: open alpha

A browser demo console on a synthetic lab. Each record gets a SHA-256 fingerprint, chained in order, and corrections are new records with a reason. The console’s seal is a keyless demo seal; the record pages on this site use demo ECDSA signatures instead. You can write a batch fingerprint by hand to a registry you deploy on a public test network.

{{consoleLink}}

2The alpha app

It imports HPLC CSV files and seals each peak area with the same five-field payload and link rule as this site. One server key signs the rows. Reviewer sign-off and verification do not work yet in the alpha.

3Planned

  • Roadmap · Agentic workflowsVerified experiment data that AI agents can check before they use it in their research and work.
  • Roadmap · Per-analyst signaturesEach record signed by the analyst who made it, in place of one server key.
  • Roadmap · Sealed metadataSample and method metadata inside the sealed record, not beside it.
  • Roadmap · Shared registryOne project registry that anyone can check, in place of registries each visitor deploys.
  • Roadmap · Filecoin integrationAnchoring and storage on Filecoin; today only a test network is used.

4Not claimed

Nothing is confirmed live. There are no customers, no electronic signatures, no validation, no instrument capture and no Filecoin storage yet.
