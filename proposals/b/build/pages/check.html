3Method

  • PayloadinstrumentId|sensorType|value|unit|capturedAt, UTF-8, no spaces around the bars: the alpha app’s canonical payload for an HPLC peak area. The alpha records peak area with the unit “counts”.
  • Fingerprintrn = SHA-256 of the payload (FIPS 180-4), as lowercase hex.
  • Linkhn = SHA-256 of the text hn−1 + rn + n (lowercase hex, then the decimal position), starting from 64 zeros.
  • SignatureECDSA P-256 with SHA-256 over the 32 bytes of rn (FIPS 186-5), IEEE P1363 encoding. Records 1 to {{AN}} were signed at build time with a demo key whose private half was then discarded. Demo key id {{keyId}} (first 16 bytes of SHA-256 of its SPKI, as the alpha app computes it). Public key, uncompressed point:{{pub}}
  • AnchorThe link of record {{AN}}, stored on this page as the anchored fingerprint (simulated, no network call). A correction moves the head on; it stays “not yet anchored” until a new anchor.
  • LimitsOn this page the public key and the anchor ship with the records, so they show the method, not independent evidence: whoever can rewrite the page can replace the key, the signatures and the anchor together. In use, both must come from outside the lab’s system: a key published elsewhere, a fingerprint on a public network.

BasisThe same link rule as the alpha app’s HPLC import and the record figure on joseqc.com.
