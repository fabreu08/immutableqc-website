3What it does today

  • Alpha console · demo in your browserRuns on a synthetic lab, only in your browser. It gives each record a SHA-256 fingerprint, links it to the record before it, signs it with a demo key made in your browser, and keeps corrections as new records with a reason. Its anchor is simulated, with no network call.
  • Alpha app · not publicImports HPLC CSV exports. Each peak area becomes a record of instrument, measurement type, value, unit and capture time, signed by one server key. Reviewer sign-off and the app’s own verification do not work yet.
  • Anchoring · manualA batch fingerprint can be written by hand to a small registry contract on a public test network. There is no shared registry yet, so every anchor on this site and in the console is simulated.
  • Not yetNo customers, no instrument capture, no electronic signatures, no validation and no Filecoin storage.

BasisThe same five fields and link rule in the alpha app’s HPLC import and on these pages. The console documents its own payload in its Method panel.

4Where it fits

Your instrument, CDS, LIMS and QA review stay as they are. In the alpha, Immutable QC sits beside the CDS export: results imported from the CSV export are sealed and linked into a tamper-evident record history, so a later change to a sealed value shows. Changes made before import are not covered.

Simulated here, with no network call. Anyone who already holds the records can recompute it and see whether they still match.

A fingerprint is not encryption. A plain SHA-256 of a few guessable fields can in principle be matched by trying likely values, which is why a single record’s fingerprint is never published. Salted commitments, and later zero-knowledge proofs, are on the roadmap so that what goes on a public network says nothing about results.

6Agentic workflows Roadmap

{{founderLine}}

José A. Fernández Abreu, founder

Planned: verified experiment data that AI agents can check before they use it. An agent would recompute the fingerprint from the fields, check the signature and the link, and compare the anchor, and treat the record as unchanged only if all four pass. That says whether a result changed after it was sealed, not whether it was right when it was captured.

Check a record shows one record the way an agent would receive it. It is labelled roadmap: there is no API today.
