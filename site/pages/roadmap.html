2.1Agentic workflows Roadmap

Verified experiment data that AI agents can check before they use it in research and work. Before using a result, an agent would recompute the fingerprint from the fields, check the signature, check the link and compare the anchor, and treat the record as unchanged only if all four pass.

Check a record shows one record the way an agent would receive it, as JSON. It is a preview, not an API. It needs a documented record schema, keys published outside the lab and a shared registry first.

IQC-CK-01 §2The agent-readable record

2.2Privacy on public networks Roadmap

Anything written to a public network should reveal nothing about results. A plain SHA-256 of a few guessable fields can in principle be matched by trying likely values, so a plain fingerprint is not enough.

  • FirstSalted (hiding) commitments in place of plain fingerprints: the lab keeps a random salt, and what is published reveals nothing without it.
  • LaterZero-knowledge proofs, so that a lab can show a property, such as “within specification” or “reviewed before release”, without disclosing the value.
  • TodayThe alpha writes only a batch or chain fingerprint, never the values, and only by hand.

2.3Filecoin integration Roadmap

Anchoring, and later storage, on Filecoin, beyond today’s manual batch fingerprint on a public test network. The registry contract for this stays in the project. The details are not decided.

2.4Per-analyst signatures and reviewer sign-off Roadmap

Each analyst and reviewer signs with their own key, in place of one server key, and second-person review is recorded as a signed record. Electronic signatures under 21 CFR Part 11 need more than a key: verified identity, the signature’s meaning, and controls over credentials.

2.5Sample and method metadata in the seal Roadmap

Sample, method, injection and retention time sealed inside each record, not shown beside it; and a correction’s reason and reference sealed with it.

2.6A shared registry Roadmap

One public registry of batch fingerprints that anyone can check, in place of a registry each person deploys.

3Not claimed

Nothing is in production use. There are no customers, no electronic signatures, no validation, no instrument capture and no Filecoin storage yet.
